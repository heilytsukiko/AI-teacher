# AI-teacher

## Прогресс пользователя (CEFR)

Модель пользователя `User` расширена полями для хранения текущего уровня:
- `CurrentCefrLevel` — текущий уровень CEFR (например, `A1`, `A2`, `B1`, `B2`, `C1`, `C2`).
- `CurrentCefrLevelUpdatedAtUtc` — когда уровень был обновлён (UTC).
- `CurrentCefrLevelUserOverride` — признак того, что уровень выставлен вручную пользователем.

Важно: в дальнейшем пользователь может изменить уровень вручную (например, с `B1` на `A2` или наоборот на более высокий), если считает, что уровень слишком сложный или слишком лёгкий.
